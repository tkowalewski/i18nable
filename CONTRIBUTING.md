# Contributing

1. Fork the repo and run `bin/setup` (requires Ruby >= 3.1).
2. Run `bundle exec rake` to execute specs (`rake spec`) and RuboCop (`rake rubocop`).
3. Run `bin/console` for an interactive prompt.
4. Add specs for your change, update `CHANGELOG.md` and open a pull request.

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
